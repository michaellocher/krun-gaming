Your Steam library on Apple Silicon, the Steam Deck way.

krun-gaming boots a Linux microVM in under a second and runs Valve's own Steam client, Proton, DXVK and vkd3d-proton inside it. The Mac GPU is reached through Vulkan on Metal. No Windows license, no Rosetta, no closed translation layer: every piece is open source and built from source.

Get started View on GitHub

A working prototype, tested on one machine: MacBook Pro M1 Pro, 16 GB, macOS 27.0.1.

What works

Measured 2026-11-08 on an M1 Pro with 16 GB. Each number comes from a run described in the lab notes.

  • 60 fps

    Direct3D 11

    Banished through DXVK at 2560×1440 runs at the display rate, menu and gameplay alike. Host ~62 % CPU, 3.2 GB.

  • 554/588

    Direct3D 12

    vkd3d-proton v3.1 test suite: tests without a failed check, with stream output (transform feedback) included.

  • ~50 fps

    Steam Big Picture

    Valve's native ARM64 client under gamescope with GPU compositing, in a Retina window at 2560×1440.

  • 1.4

    Vulkan in the guest

    Vulkan 1.4 with swapchain on the M1 Pro: Venus → virglrenderer → Mesa KosmicKrisp → Metal.

  • ▶

    Shared textures

    Textures shared between Wine processes work: InfraSpace's Media Foundation intro video plays. Guest images are shared as Metal heaps on the host.

  • ♪

    Sound, microphone, input

    virtio-snd to CoreAudio: playback on the Mac's default output, the Mac's microphone as capture device; keyboard and absolute mouse through virtio-input.

  • 0

    Closed translation layers

    Kernel, Mesa, virglrenderer, libkrun, gamescope, FEX, Proton: all open source, built at pinned commits, with patches listed openly. Only Steam and your games are Valve's and theirs.

Quick start

Needs an Apple Silicon Mac, Xcode, Homebrew, rustup and Node 26, plus a Steam account with your own games.

git clone https://github.com/michaellocher/krun-gaming
cd krun-gaming
bash setup.sh        # builds everything into ~/.local/share/krun-gaming
sh run-session.sh    # Steam Big Picture in a Mac window

Log in to Steam in the window, install a game, play. A fresh setup.sh took 21 minutes on an M1 Pro; it skips every step whose output already exists. Steam downloads at the full line rate.

Known limits

  • Prototype. Tested on one machine (M1 Pro, 16 GB).
  • D3D12: some edge cases of the test suite still fail: texture reinterpretation, border colours, tessellation, suballocation alignment.
  • Steam UI: Valve's GL composer in the UI still renders on the CPU.
  • Static game windows: a launcher that draws only once can stay behind Steam's loading spinner until you click into it.
  • Anti-cheat: games whose anti-cheat refuses VMs will not run.
